# AgriQueue+

A modern agricultural queue management system designed to streamline farming operations and optimize resource allocation.

## Project Structure

```
AgriQueue+/
├── backend/          # Node.js server
│   ├── package.json
│   └── server.js
├── frontend/         # Web interface
│   └── AgriQueue_Plus.html
├── README.md
└── .gitignore
```

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

The server will run on `http://localhost:3000` (or as configured in server.js).

### Frontend Setup

Open `frontend/AgriQueue_Plus.html` in your web browser to access the application.
